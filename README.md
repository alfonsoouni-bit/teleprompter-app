# Teleprompter Web

Aplicación web diseñada para la asistencia en lectura continua de guiones y presentaciones.

## Características
- Área de edición con botones de acción directa (Pegar, Limpiar, Ejecutar, Pausar y Reiniciar).
- Control dinámico de velocidad de desplazamiento y tamaño tipográfico.
- Indicador visual de estado operativo (activo/detenido).
- Atajo de teclado: Barra espaciadora para alternar entre pausa y reproducción.

## Estructura del proyecto
- `/css`: Hojas de estilo de interfaz y pantalla de lectura.
- `/js`: Lógica de desplazamiento continuo y gestión de eventos.
- `/img`: Recursos gráficos para el indicador de estado.
- `index.html`: Estructura principal de la aplicación.

## Despliegue
Diseñado para servirse mediante servidores web como Nginx o Apache como contenido estático optimizado.
